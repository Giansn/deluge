# mastertune for the Deluge (community firmware 1.2.1)

Everything about mastertune is in the [README at the top of the repository](../README.md): what it adds, the downloads, the screenshots and every version with its details and measurements.

This folder holds the files it names: the firmware `.bin` files and their `.symbols.json`, `patches/`, `tools/`, `tests/`, `docs/`, `device/`, `research/` and the test versions (`perf/`, `diag/`, `prof/`, `l2test/`, `hotfix/`).
