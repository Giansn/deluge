4. The Deluge as a USB audio interface

Connect the Deluge to a computer by USB, and the computer sees a stereo audio input next to the usual MIDI ports. It receives exactly what is at the Deluge's outputs, bit-exact, without a driver. v8

4.1 What the computer receives

  • Stereo, 24 bit, 44.1 kHz, as a standard USB audio device (USB Audio Class 1.0). No driver needed.
  • The Deluge's output signal, bit-exact: the same signal the Deluge records when resampling, with the master volume and input monitoring. The drone is in it too (chapter 9).
  • The Deluge controls the level. The computer has no volume control for this input. The Deluge's analog VOLUME knob acts after the converter, so it doesn't change the USB signal either.
  • One direction only: from the Deluge to the computer. Audio from the computer to the Deluge is not there yet.

4.2 Switching it on

  1. Open Settings → Community features → USB audio (7-segment UAUD) and set it to on.
  2. Restart the Deluge. The setting only takes effect at startup, and only when the Deluge is connected to the computer as a USB device, not as a USB host.
  • From v16 on the Deluge saves this setting immediately. Up to v15 it was saved only when you left the menu: leave it with BACK before you restart.
  • Off is the default. Then the Deluge behaves as without USB audio.

To record without a DAW, use DelugeRec (§8.2). It names each take after the song.

4.4 Timing and latency

  • The Deluge sets the clock. Each USB packet carries 44 or 45 frames, depending on how full its buffer is. If its crystal drifts against the computer's clock, it sends one frame more or less. Nothing is resampled; the samples arrive bit-exact.
  • Latency: about 6 ms of buffer plus 1–2 ms for USB.
  • Hiccups: if the computer stops reading for a while, the Deluge discards the stale buffer and starts again after 6 ms of silence. If the audio engine stalls, a short silence comes instead of crackles.
  • MIDI is not affected by the audio stream.

4.5 The song name for recordings v18

While the computer has the audio stream open, the Deluge reports the song name and the firmware version on USB MIDI port 3. DelugeRec uses this to name its takes, for example "Song name, 28.09.2026 - 1.2.1 v18.3.WAV" (§8.2). The Deluge only sends this; it never waits for an answer. Because USB doesn't run in the emulator, this has to be confirmed on the device.

4.6 Limitations and messages

SituationWhat to know
Other sample ratesOnly 44.1 kHz. If the DAW runs at another rate, the operating system resamples. In exclusive mode or with ASIO the project must be at 44.1 kHz.
MIDI ports movedWith USB audio on, the computer sees the Deluge as a new device. You may have to assign the MIDI ports in your DAW again.
Not recognised or hangsUnplug the USB cable, start the Deluge, switch USB audio off.
UGAP, "USB audio gap"The computer got an empty packet: a 1 ms gap in the recording. This can happen under very high load, because the Deluge disables all interrupts while it computes each track. The message comes at most every 10 seconds. Please report it (§11.8).
