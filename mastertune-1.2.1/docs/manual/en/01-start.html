1. Getting started

mastertune is a personal fork of the official Deluge community firmware 1.2.1 with a set of changes on top. This chapter tells you which file to install, how to install and check it, and how to go back. Everything this manual does not describe works exactly as in 1.2.1.

1.1 What changes against 1.2.1

1.2 Which file to install

The current version is v18.3. All firmware files are in the folder mastertune-1.2.1/ of the repository github.com/Giansn/deluge. You need one of these:

FileWhat it is
deluge-1.2.1-mastertune-v18.3-l2d-3581f019.binThe current version. With the L2 cache for code and data (§1.5). v18.3 exists only in this variant.
deluge-1.2.1-mastertune-v18-124aeaa2.binv18 without the L2 cache, for switching back if the L2 variant crashes or behaves strangely. It lacks the fixes of v18.2 and v18.3.
deluge-1.2.1-mastertune-v17-2cb5e31b.binv17 without the L2 cache.

Every earlier version from v2 on is in the same folder (history in §11.7). Next to the newer files lies a .symbols.json of the same name. It holds the function names for the profiler (§8.6) and fits only exactly that .bin.

1.3 Installing

Keep a copy of your SD card before you install. v18.x has not been played on a real Deluge yet (§1.7).
  1. Copy the .bin file into the root folder of the SD card. Leave no other .bin file there.
  2. Hold SHIFT while you switch the Deluge on. The Deluge installs the firmware.
  3. Check the version (§1.4).

This is the same procedure as for any Deluge firmware.

1.4 Checking the version

Open Settings → Firmware version. From v18 on the OLED shows the name in the normal font, on up to three lines and without the hash: 1.2.1-mastertune- / v18.3-l2d. The hash stays in the file name.

Up to v17 the name included the hash, for example 1.2.1-mastertune-v17-l2d-b3385d83.

When you report a problem, always give this name (§11.8).

1.5 The L2 cache files v17

l2d in a file name means: this firmware uses the processor's L2 cache for code and data. From v17 on this is the main file, and v18.2 and v18.3 exist only this way.

  • Why: every pass of the audio routine reads more data than fits into the processor's small first-level cache. The L2 cache holds it closer. With v16-l2d the song "New Sitar Grii 10" sounded audibly better on the device, and there was no crash.
  • Not in the numbers: the CPU comparison with 1.2.1 in chapter 3 comes from an emulator without a cache model. The L2 cache should add to the gain on the device, but that is not measured yet.
  • If it crashes or behaves strangely: install deluge-1.2.1-mastertune-v18-124aeaa2.bin, v18 without L2, and report what happened (§11.8).

1.6 Going back

To go back, install the other firmware exactly as in §1.3: to v18 without L2 with the file from §1.2, to 1.2.1 with its official file. Your songs keep loading. What happens to the new things:

Saved with mastertuneIn an older mastertune version or in 1.2.1
Master tuneThe official firmware does not know the entry in CommunityFeatures.XML. It keeps it anyway and writes it back unchanged.
Volume in dBSaved as before. Songs sound equally loud and still load in v17.
Arpeggiator additions1.2.1 loads the song but skips the kit arp, randomizer, latch and bounce, and loses them at the next save. Walk and Pattern become Up.
Reverb model DigitalThe song plays without reverb in 1.2.1.
Reverb dampingStored as in 1.2.1, so songs stay interchangeable.
Drone and drone tracksOlder firmware skips the drone and the drone rows. Don't save such a song there: the drone rows get lost (chapter 9).
Community settingsv18.3 keeps settings it doesn't know. 1.2.1 and v17 don't: after switching to v17 and back, Output limiter, Filter crossing guard and OLED brightness are back at their defaults.

1.7 How it's tested

  • Reproducible: every release is built twice, and both builds are byte for byte the same.
  • In an emulator: the firmware's own machine code for the Deluge's processor (an ARM Cortex-A9) runs in an emulator. It boots, loads songs, renders audio and goes through hundreds of checks and stress tests. Reverb, delay and drone are also measured on the PC.
  • Reviewed: independent reviewers checked the larger changes with their own test cases.
  • The limit: the emulator is not the hardware. Timing, the SD card and USB can behave differently on a real Deluge. USB does not run in the emulator at all.
  • On the device: earlier versions ran on a real Deluge, v16 and its L2 variant among them. v18.x has not been played on a real Deluge yet. The listening tests for it are in 5.12.
mastertune is a personal fork, written with Claude (AI), not a contribution to the official firmware. Please don't report its bugs to the community developers. Report them at github.com/Giansn/deluge/issues (§11.8).
